# RockGod® Build Engine Alpha V0.2

This is a static prototype for customer testing. It does not collect personal data or process payments.

## What changed from V0.1
- Clearer hair + beard purpose on the welcome screen
- Slightly stronger RPG / character-builder language while keeping the premium black / white / gold look
- Mobile progress moved to a compact bottom navigation bar
- Four-card hair and beard screens tightened for mobile
- Grayscale image treatment made more consistent
- Selection changes now preserve scroll position instead of jumping to the top
- Nemesis explained in plain English
- New “What’s been holding you back?” step
- Loadout now explains why each product role was selected
- Added a £9.95 First Loadout conversion hypothesis and demo Buy Now state

## Important Alpha limitations
- The central Final Build portrait is still illustrative rather than a true dynamic hair + beard composite.
- Product names, product roles, sample contents and £9.95 pricing are working hypotheses only.
- No checkout is connected.

## Publish to the existing GitHub Pages site
Replace the existing `index.html` in the repository with this V0.2 `index.html`, and replace/upload the `assets` folder if needed. Commit the changes. GitHub Pages should redeploy automatically.
