# RockGod® Build Engine — Alpha V0.6.1

## Hotfix + content refinement

V0.6.1 keeps the Bridge Loadout logic from V0.6 and fixes the issues found during the latest walkthrough.

### Changes

- Fixed the oversized Final Build portrait on Step 4
- Fixed the same oversized portrait issue on Step 7 / Loadout summary
- Kept the faster preload/prefetch behaviour from V0.6
- Screen 5 is now **WHAT’S YOUR NEMESIS?**
- Nemesis = the ONE grooming problem to tackle now
- Screen 6 remains **WHAT’S BEEN HOLDING YOU BACK?**
- Barrier options are now clearly distinct:
  - I don’t know where to start
  - I’m not sure what actually suits me
  - I’ve tried things before and they haven’t worked
  - I don’t want a complicated routine
  - I don’t want to spend ages doing it
  - I don’t want to waste money on the wrong products
- Removed duplicated Current → Target wording in the Loadout screen
- Replaced the generic Equip Guide with an actual mini routine based on the recommended products
- First Quest now asks the customer to notice what changes, what still gets in the way, and how their Build develops

### Journey

**Your Build → Your Nemesis → What’s been holding you back → Your Bridge Loadout**
