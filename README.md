# RockGod® Build Engine — Alpha V0.6

## Purpose

V0.6 is the friends-and-family blind-test build.

Core recommendation philosophy:

**Current Build sets the guardrails. Target Build sets the direction.**

The First Loadout is a **Bridge Loadout**: products the customer can use now, selected with the Build they are working towards in mind.

## V0.6 changes

- Stronger opening hook: **You’re the Main Character**
- “We’re in your corner” moved off the opening screen and onto the final relationship/continuation stage
- Standardised typography for:
  - Looking to Change
  - Happy Where I Am
  - Preview the Next Quest
- Step 3 renamed to **What are you building towards?**
- Step 4 now explains that the target portrait is the destination Build
- All 24 portrait assets begin preloading at site launch
- The exact selected Final Build is prefetched as soon as Target Hair/Beard are chosen
- Recommendation engine now materially uses both Current Build and Target Build
- Short hair growing towards medium/long hair is no longer automatically given short-hair clay
- Long-hair styling remains conditioner + leave-in rather than clay
- Step 7 is reframed around gear for the next stage of the Quest
- Product cards still explain: what it is, what it does, why it is included, and how to use it
- Final page carries the brand promise:
  **Not just in your bathroom cabinet. We’re in your corner.**
- £9.95 remains a test offer only; no payment or personal data is collected

## Blind-test questions

Send the live link without explaining RockGod first, then ask:

1. What did you think RockGod was within the first 10 seconds?
2. Did Current Build → Target Build make sense?
3. Did the Final Build image feel like a useful destination?
4. Did the sample recommendation feel relevant to both where you are now and where you are heading?
5. Could you explain what each recommended product was for?
6. Would you click the £9.95 First Loadout button? Why / why not?
7. Did “Continue Your Quest” make you curious to keep going?
