# RockGod® Build Engine — Alpha V0.5

## What's new
- Existing approved grayscale hair/beard reference assets and standalone 16-combination Final Build matrix retained. All images are root-level for easy GitHub upload.
- Single-select top priority; priorities automatically filtered to customers' current hair/beard (no beard complaint for clean-shaven users; no hair-styling complaint for shaved-head users). Removed the unvalidated “Style doesn't last” choice.
- Working decision rules based on CURRENT hair length, beard and ONE priority; the target is reflected in the explanation and later Quest, not used to prescribe gear someone cannot use today.
- Two introductory minis for most routes, one provisional scalp-care mini for shaved and clean-shaven; scalp care is UNCONFIRMED and must not be offered for sale before suitability, price and size checks.
- Priority-specific headings/explanations; barrier-specific guidance. Product cards define what each product is, does, why it was chosen and how to start using it.
- £9.95 illustrative demo with no imaginary crossed-out “was” price. Body wash is a separate opt-in conceptual add-on, not a free mini. Wallet buttons are non-payment demonstrations.
- Continue Your Quest route introduces optional future deeper character experience without collecting personal information or promising live AI support.
- Friends-and-family blind-test prompts included at the end.

## Publish to GitHub Pages
1. Extract this ZIP. In the GitHub repository choose Add file → Upload files.
2. Upload **all files inside this folder together**, not the ZIP or an enclosing folder: `index.html`, `README.md`, and 24 `.webp` assets. If GitHub asks to replace matching files, confirm the replacement. Existing older image assets can remain harmlessly for now.
3. Commit using `RockGod Alpha V0.5 – recommendation engine and tester flow`.
4. Wait for GitHub Pages deployment; refresh on phone. Check the welcome version badge reads V0.5.

## Blind-test procedure
Give a friend the URL without explaining the journey. Ask them to narrate what they're thinking, but don't coach them. After the final page ask: (1) What do you think RockGod does? (2) Did the selected combined portrait match your choices? (3) Why were those samples suggested? (4) Could you explain how you'd use them? (5) Would you click the £9.95 offer, and why/why not? (6) Where did you hesitate? Capture their exact words; do not collect health or other sensitive information.

## IMPORTANT prototype limitations
No analytics, orders, email, personal profiles, payment processing, AI support or live follow-ups. Wallet buttons and £9.95 are demos. All product pairings, names, directions and claims are working assumptions, not verified Options stock/formulas. Scalp care is not yet validated, nor is SPF claimed. A one-mini £9.95 value proposition requires separate commercial testing. This website should be shared **for prototype testing only**, not promoted as a live sales site.

## Decision rules quick QA
- Short hair + flat → shampoo + texture spray.
- Medium hair + difficult to style → shampoo + texture spray.
- Long hair + difficult to style → conditioner + leave-in (never clay).
- Hair + rough beard → beard oil + shampoo (short/medium) or conditioner (long).
- Bald + beard → beard oil + provisional scalp care.
- Bald + clean-shaven → provisional scalp care ONLY.
- Clean-shaven → beard roughness is not offered.
- Bald → hair styling/dryness concerns are not offered.
- Barrier changes explanation only; it never adds products.
- Body wash never enters the starter kit.
