# RockGod Build Engine — Alpha

A free, static, mobile-responsive **prototype**, not a live shop. No forms, tracking, accounts, checkout or customer-data collection. Open `index.html` locally to try it.

## Publish with GitHub Pages

1. Create a **public** GitHub repository (for example `rockgod-alpha`). Do not upload secrets or unpublished sensitive information.
2. Upload `index.html` and the entire `assets/` folder to the repository root. Keep the filenames and folder structure unchanged.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, then save.
4. Once GitHub shows the published URL, open it on your phone and test the six steps. Pages deployment may take a few minutes. The public link is usually `https://YOUR-USERNAME.github.io/rockgod-alpha/` but use the actual URL shown in GitHub settings.

## Current limits

- The welcome screen offers two paths: **Looking to change** and **Happy where I am**. The latter copies the current selections to the target Build.
- Hair and beard portraits are cropped from the approved concept artwork. The Final Build central portrait is a **static illustrative placeholder**; the selected hair and beard cards accurately reflect user choices but are **not yet composited into a new portrait**.
- The target screen and edit buttons are functional. Nemesis is a clickable placeholder, and the Loadout is a non-commercial summary, not a product recommendation.
- The final wording, mobile image assets, texture options, accessibility, product suitability, price, tutorials and ecommerce integration need further work.
- No live link has been created by this package. Publication requires the account owner to upload it.

## Test questions

Can a new visitor understand the purpose without explanation? Can they select hair and beard, keep their current look, change target selections, edit their Build and reach the Loadout on a phone? Do they understand that the central portrait is not yet personalised?
